Conectar um número

Um passo de cada vez. O próximo só aparece quando o anterior termina.

  1. 1 Dê um nome ao número

    É o nome da instância na Evolution. Se o número JÁ existe lá, digite o nome exato dela e pule para o passo 3.

  2. 2 Leia o QR no celular

    WhatsApp → Aparelhos conectados → Conectar aparelho. O código expira em pouco tempo; se expirar, peça outro.

  3. 3 Confirme que conectou

    O webhook é o que faz as mensagens dos grupos chegarem aqui. Só é necessário para número que vai OBSERVAR grupos.

Criar um grupo de ofertas

O número escolhido acima vira o dono do grupo. A Evolution exige pelo menos um participante para criar — pode ser o seu outro número. Depois você divulga pelo link de convite.
